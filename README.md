# Hotel Management Database System

## Overview
This project is a Hotel Management Database System developed using MySQL Workbench. It manages hotel information, room details, customer records, and bookings through a relational database.

## Features
- Hotel management
- Room management
- Customer management
- Booking management
- SQL queries for data retrieval and updates

## Technologies Used
- MySQL
- MySQL Workbench
- SQL

## Database Tables
- Hotel
- Rooms
- Customers
- Bookings

## How to Run
1. Open MySQL Workbench.
2. Create a new database.
3. Import and execute the `hotel_management.sql` file.
4. Run the SQL queries included in the script.
